Using the FireFly Probe in MATLAB

1. Introduction

The PMK FireFly is a high-performance active oscilloscope probe designed for precise voltage measurements. This guide demonstrates how to control the FireFly probe using MATLAB by calling the pmk-probes Python package through MATLAB's Python integration.

Key Features of the FireFly Probe:

  • Input voltage range: -1V to +1V
  • Fixed attenuation ratio: 1:1
  • Battery-powered probe head for isolated measurements
  • Auto-zero calibration capability
  • Status LED indicators for probe state
  • Built-in battery level monitoring
  • Propagation delay compensation

2. Prerequisites

Before you begin, ensure you have the following:

  • MATLAB: R2019b or later (for full Python integration support)
  • Python: Version 3.10 or higher installed on your system
  • Hardware:
    • PMK FireFly probe
    • PMK PS02 or PS03 power supply
    • USB or serial connection to the power supply
  • Drivers: Appropriate USB/serial drivers for your power supply
Compatibility Note: MATLAB R2019b and later versions have improved Python integration. For best results, use MATLAB R2021a or newer.

3. Installation

3.1 Install Python Package

First, install the pmk-probes Python package using pip. Open a command prompt or terminal and run:

pip install pmk-probes

This will install the package and its dependencies (including pyserial).

3.2 Verify Installation

Verify the installation by running Python and importing the package:

python -c "import pmk_probes; print('Installation successful!')"

4. Setting Up Python in MATLAB

4.1 Check Python Version in MATLAB

In MATLAB, check which Python version is configured:

pyenv

This will display information about the current Python environment.

4.2 Configure Python Environment (if needed)

If MATLAB is not using the correct Python version, you can specify the Python executable:

% On Windows
pyenv('Version', 'C:\Python310\python.exe')

% On Linux/Mac
pyenv('Version', '/usr/bin/python3.10')
Important: You must restart MATLAB after changing the Python environment for the changes to take effect.

4.3 Verify Package Access

Verify that MATLAB can access the pmk_probes package:

% Try to import the package
py.importlib.import_module('pmk_probes.probes')
disp('Package accessible from MATLAB!')

5. Basic Usage

5.1 Connecting to the Probe

To use the FireFly probe, you first need to connect to the power supply and create a FireFly object:

% Import required Python modules
PS03 = py.importlib.import_module('pmk_probes.power_supplies').PS03;
FireFly = py.importlib.import_module('pmk_probes.probes').FireFly;
Channel = py.importlib.import_module('pmk_probes.power_supplies').Channel;

% Connect to the power supply
% Replace 'COM3' with your actual COM port (Windows)
% or '/dev/ttyUSB0' (Linux) or '/dev/tty.usbserial-XXX' (Mac)
ps = PS03('COM3');

% Create FireFly probe object on channel 1
firefly = FireFly(ps, Channel.CH1);
Finding Your COM Port:
  • Windows: Check Device Manager under "Ports (COM & LPT)"
  • Linux: Run ls /dev/ttyUSB* or dmesg | grep tty
  • Mac: Run ls /dev/tty.usb*

5.2 Reading Probe Metadata

You can read various metadata from the probe, including serial number, model information, and calibration dates:

% Get probe metadata
metadata = firefly.metadata;

% Access specific metadata fields
serial_number = char(metadata.serial_number);
model = char(metadata.model);
manufacturer = char(metadata.manufacturer);
production_date = char(metadata.production_date);
calibration_due = char(metadata.calibration_due_date);
hw_revision = char(metadata.hardware_revision);
sw_revision = char(metadata.software_revision);
prop_delay = double(metadata.propagation_delay);

% Display metadata
fprintf('FireFly Probe Information:\n');
fprintf('  Serial Number: %s\n', serial_number);
fprintf('  Model: %s\n', model);
fprintf('  Manufacturer: %s\n', manufacturer);
fprintf('  Hardware Revision: %s\n', hw_revision);
fprintf('  Software Revision: %s\n', sw_revision);
fprintf('  Production Date: %s\n', production_date);
fprintf('  Calibration Due: %s\n', calibration_due);
fprintf('  Propagation Delay: %.2f ns\n', prop_delay);

5.3 Controlling the Probe Head

The FireFly probe has a battery-powered probe head that must be turned on for measurements:

% Turn on the probe head
firefly.probe_head_on = py.bool(true);

% Check if probe head is on
is_on = logical(firefly.probe_head_on);
fprintf('Probe head is: %s\n', string(is_on));

% Wait for probe to warm up
% The probe goes through states: WARMING_UP -> READY_TO_USE
pause(3);  % Wait 3 seconds

% Check probe status
status = firefly.probe_status_led;
fprintf('Probe status: %s\n', char(status.name));

% Turn off the probe head when done
firefly.probe_head_on = py.bool(false);

Probe States

State Description
NOT_POWERED Probe is not receiving power
PROBE_HEAD_OFF Probe head is turned off
WARMING_UP Probe is warming up (takes a few seconds)
READY_TO_USE Probe is ready for measurements
EMPTY_OR_NO_BATTERY Battery is empty or not connected
ERROR An error has occurred

5.4 Auto-Zero Calibration

The auto-zero function calibrates the probe's offset. This should be performed with the probe disconnected from the circuit under test:

% Ensure probe head is on
firefly.probe_head_on = py.bool(true);

% Wait for probe to be ready
pause(3);

% Disconnect probe from circuit and perform auto-zero
firefly.auto_zero();

fprintf('Auto-zero calibration completed.\n');
Important: Always disconnect the probe from the circuit before performing auto-zero calibration. The probe input should be at ground potential (0V) during calibration.

5.5 Battery Status

Monitor the battery status to ensure reliable operation:

% Turn on probe head (required for battery reading)
firefly.probe_head_on = py.bool(true);
pause(1);  % Allow time for reading to stabilize

% Get battery voltage
voltage = double(firefly.battery_voltage);
fprintf('Battery voltage: %.2f V\n', voltage);

% Get battery indicator (4 LEDs from bottom to top)
indicator = firefly.battery_indicator;

% Convert Python tuple to MATLAB
led_states = cell(indicator);
fprintf('Battery indicator LEDs:\n');
for i = 1:4
    led = led_states{i};
    fprintf('  LED %d: %s\n', i, char(led.name));
end
Note: Battery voltage is not available immediately after turning off the probe head. Wait approximately 200 milliseconds before reading the battery voltage after changing the probe head state.

Battery LED States

LED State Meaning
OFF LED is off
GREEN Battery level is good
YELLOW Battery level is moderate
BLINKING_RED Battery level is low (needs charging)

6. Advanced Features

6.1 Reading Probe Properties

Get information about the probe's capabilities:

% Get probe properties
props = firefly.properties;

% Access voltage range
v_range = props.input_voltage_range;
min_voltage = double(v_range{1});
max_voltage = double(v_range{2});
fprintf('Input voltage range: %.1f V to %.1f V\n', min_voltage, max_voltage);

% Access attenuation ratios
attn_map = props.attenuation_ratios;
fprintf('Attenuation ratio: 1:1 (fixed)\n');

6.2 Working with Power Supply Channels

If you have multiple probes, you can create objects for different channels:

% Import modules
PS03 = py.importlib.import_module('pmk_probes.power_supplies').PS03;
FireFly = py.importlib.import_module('pmk_probes.probes').FireFly;
BumbleBee2kV = py.importlib.import_module('pmk_probes.probes').BumbleBee2kV;
Channel = py.importlib.import_module('pmk_probes.power_supplies').Channel;

% Connect to power supply
ps = PS03('COM3');

% Create multiple probe objects
firefly1 = FireFly(ps, Channel.CH1);
firefly2 = FireFly(ps, Channel.CH2);
bumblebee = BumbleBee2kV(ps, Channel.CH3);

% Control different probes independently
firefly1.probe_head_on = py.bool(true);
firefly2.probe_head_on = py.bool(true);

6.3 Expert Mode

The FireFly probe has an expert mode that unlocks additional features:

% Enable expert mode (use with caution)
firefly.enable_expert_mode();
Warning: Expert mode provides access to advanced features that should only be used by experienced users. Incorrect use may affect probe calibration or functionality.

7. Complete Examples

Example 1: Basic Probe Setup and Calibration

% Complete example for setting up and calibrating a FireFly probe

% Import modules
PS03 = py.importlib.import_module('pmk_probes.power_supplies').PS03;
FireFly = py.importlib.import_module('pmk_probes.probes').FireFly;
Channel = py.importlib.import_module('pmk_probes.power_supplies').Channel;

% Connect to power supply (adjust COM port as needed)
ps = PS03('COM3');

% Create FireFly probe on channel 1
firefly = FireFly(ps, Channel.CH1);

% Display probe information
metadata = firefly.metadata;
fprintf('Connected to FireFly probe:\n');
fprintf('  Serial Number: %s\n', char(metadata.serial_number));
fprintf('  Model: %s\n', char(metadata.model));

% Turn on probe head
fprintf('Turning on probe head...\n');
firefly.probe_head_on = py.bool(true);

% Wait for warm-up
fprintf('Waiting for probe to warm up...\n');
pause(3);

% Check status
status = firefly.probe_status_led;
fprintf('Probe status: %s\n', char(status.name));

% Perform auto-zero calibration
fprintf('Performing auto-zero calibration...\n');
fprintf('Please ensure probe is disconnected from circuit.\n');
pause(2);  % Give user time to disconnect
firefly.auto_zero();
fprintf('Calibration complete!\n');

% Check battery status
voltage = double(firefly.battery_voltage);
fprintf('Battery voltage: %.2f V\n', voltage);

% Ready for measurements
fprintf('Probe is ready for use!\n');

% When done, turn off probe head
fprintf('Turning off probe head...\n');
firefly.probe_head_on = py.bool(false);
fprintf('Done.\n');

Example 2: Battery Monitoring Script

% Monitor battery status over time

% Import modules
PS03 = py.importlib.import_module('pmk_probes.power_supplies').PS03;
FireFly = py.importlib.import_module('pmk_probes.probes').FireFly;
Channel = py.importlib.import_module('pmk_probes.power_supplies').Channel;

% Connect and setup
ps = PS03('COM3');
firefly = FireFly(ps, Channel.CH1);
firefly.probe_head_on = py.bool(true);

% Monitor battery for 60 seconds
fprintf('Monitoring battery status...\n');
voltages = [];
times = [];

for i = 1:60
    % Read battery voltage
    v = double(firefly.battery_voltage);
    voltages(end+1) = v;
    times(end+1) = i;
    
    % Display current status
    fprintf('[%02d s] Battery: %.2f V\n', i, v);
    
    pause(1);
end

% Plot results
figure;
plot(times, voltages, 'b-', 'LineWidth', 2);
xlabel('Time (s)');
ylabel('Battery Voltage (V)');
title('FireFly Probe Battery Voltage Over Time');
grid on;

% Turn off probe
firefly.probe_head_on = py.bool(false);
fprintf('Monitoring complete.\n');

% Working with multiple FireFly probes

8. Troubleshooting

Common Issues and Solutions

Issue: "Unable to resolve the name py.importlib.import_module"

Solution: This means Python is not properly configured in MATLAB. Check:
  • Run pyenv to verify Python is detected
  • Ensure Python 3.10+ is installed
  • Restart MATLAB after configuring Python

Issue: "ModuleNotFoundError: No module named 'pmk_probes'"

Solution: The pmk-probes package is not installed in the Python environment MATLAB is using.
  • Check which Python MATLAB is using: pyenv
  • Install the package for that specific Python: pip install pmk-probes
  • You may need to use the full path to pip, e.g., C:\Python310\Scripts\pip.exe install pmk-probes

Issue: "Serial port error" or "Cannot connect to power supply"

Solution:
  • Verify the COM port is correct (check Device Manager on Windows)
  • Ensure no other program is using the COM port
  • Check that the power supply is connected and powered on
  • On Linux, you may need permissions: sudo usermod -a -G dialout $USER

Issue: "Battery voltage reads 0.0"

Solution:
  • Wait ~200ms after turning off the probe head before reading battery voltage
  • Ensure the probe head is or was recently on
  • Check battery connection and charge level

Issue: "Probe status shows ERROR"

Solution:
  • Check battery level - it may be too low
  • Power cycle the probe (turn probe head off and on)
  • Check connections to the power supply
  • Consult PMK support if error persists

Issue: Converting Python types to MATLAB

Solution: Use appropriate conversion functions:
  • Strings: char(python_string)
  • Numbers: double(python_number)
  • Booleans: logical(python_bool) or py.bool(matlab_bool)
  • Lists/Tuples: cell(python_list)

Getting Help

If you encounter issues not covered here:

  • Check the online documentation
  • Review the Python package documentation for additional details
  • Contact PMK support at www.pmk.de
